# MajorProject

A full-stack web application for creating and browsing listings, with user accounts and reviews. Users can create listings, leave reviews, and manage their own content.

## Features

- Browse listings and view listing details
- Create, edit, and delete listings
- Register and log in to an account
- Add reviews to listings
- Delete your own reviews
- Restrict listing changes to the listing owner
- Restrict review deletion to the review author
- Display success and error messages

## Tech Stack

- **Runtime:** Node.js
- **Server:** Express
- **Database:** MongoDB with Mongoose
- **Views:** EJS
- **Authentication:** Passport
- **Validation:** Joi
- **Styling:** Bootstrap
